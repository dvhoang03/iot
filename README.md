Đây là một dự án iot đơn giản để cập nhật theo thời gian thực các giá trị của cảm biến nhiệt độ, ánh sáng, độ ẩm và điểu khiển đèn led, quạt và điều hoà không khí
Dự án sử dụng frontend là ngôn ngữ Reactjs, backend là Expressjs
Tải về dự án
- Chạy frontend :
  + cd fe
  + npm start
- Chạy Backend:
  + cd be
  + npm start
- Phần cứng: ở đây sử dụng ESP8266 dùng để điều khiển.Để nạp code vào ESP8266 thì cần download Arduino IDE.
